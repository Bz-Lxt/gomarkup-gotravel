帮我用Go语言实现一个差旅与户外：多人自驾/徒步旅行"实时足迹共享与路线路书编排"平台（Mini 旅行路书）

业务背景：专为驴友或团队自驾设计的全栈出行系统。队长可以提前规划包含"多经停点、小众打卡点、住宿点"的路书，在出行期间，所有队员的实时位置都能在同一个地图上共享。

前端页面 (Vue 3 + Mapbox GL / Leaflet + 实时 WebSocket 轨迹)：路书编辑器：在地图上点击生成经纬度路径点，支持一键拖拽调整路线顺序，自动计算总里程。多人实时位置大屏：组队出行后，地图上平滑移动显示所有队员的头像和网络状态，队长可一键向全员发送紧急集合通知。旅行手账/照片墙：在地图指定的坐标点上直接上传照片，形成富有立体感的"足迹照片墙"。

Go 后端核心实现：路线依赖树与地理信息存储：管理一条线路上几十个景点的先后依赖顺序。使用空间空间索引（基于 Redis Geo 或本地 R-Tree）快速计算"当前离队伍最远的队员"并发出掉队预警。高频 WebSocket 消息扇出优化（Message Fan-out）：当队伍有 20 人、每人每秒都在上报 GPS 时，后端面临高频的并发广播风暴。需要手写高弹性的 Channel 缓冲区进行流量限制与合并转发。

文件数与代码量：约 34+ 个 Go 文件，代码量 6500 - 9000 行。
